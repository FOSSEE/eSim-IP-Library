# seqdet31 - Overlapping Sequence Detector (1011)

## Description
An Overlapping Sequence Detector targeting the specific 4-bit pattern "1011". It utilizes a resource-efficient Sliding-Window Pipeline shift register paired with a combinational match engine to monitor serial data streams without dropping consecutive overlapping bits.

## Pin Configuration

* **Outputs (1):** seq_found (1)
